当前网址不支持安装和离线保存。请打开 HTTPS 在线版，再按下面步骤安装。

  1. 用 Chrome 打开游戏

    在安卓手机的 Chrome 中打开当前网址。

  2. 菜单 → 安装应用

    点右上角「⋮」，选择「安装应用」或「安装并创建快捷方式 → 安装」。部分版本显示「添加到主屏幕」。

  3. 回到桌面，点击水果图标

    从「水果乱斗」图标进入游戏；横屏和竖屏都可以玩。

若仍有地址栏，请在 Chrome 菜单中选择「安装」应用。电脑也可使用 Chrome / Edge 的安装按钮。

Chrome 官方安装指引 ↗
  1. 用 Safari 打开游戏

    在 iPhone / iPad 的 Safari 中打开当前网址。

  2. 共享 → 添加到主屏幕

    点共享按钮（方框向上箭头）；部分布局需先打开页面菜单，再点「共享」。向下找到「添加到主屏幕」。

  3. 添加为网页 App，再从桌面进入

    若出现「作为网页 App 打开」，保持开启，再点「添加」。回到主屏幕，点击「水果乱斗」图标。

找不到该选项时，在共享菜单底部点「编辑操作」。安装后隐藏浏览器工具栏，系统状态栏和手势条可能仍保留。
